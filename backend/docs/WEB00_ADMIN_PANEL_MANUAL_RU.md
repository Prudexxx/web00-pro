# WEB00 Admin Panel Manual

## Создание и редактирование карточки сайта

Обязательные поля:

- Название
- Slug
- Категория
- Короткое описание

Slug должен быть уникальным. Если slug уже занят, форма покажет ошибку рядом
с полем slug.

## Режим демо

Поле `Режим демо` выбирается из списка. Технические значения `none` и
`external-iframe` не вводятся вручную.

Доступные варианты:

- `Без демо` - используйте, если отдельной рабочей ссылки нет.
- `Внешнее демо` - используйте, если у карточки есть внешняя demo-страница.

При выборе `Без демо` публичная карточка покажет действие `Подробнее`.
Существующие URL-поля не очищаются автоматически; при необходимости их можно
очистить вручную.

При выборе `Внешнее демо` поля ссылок остаются доступными как обычно. Отдельный
URL не становится обязательным без дополнительного требования.

## Ошибки формы

После ошибки форма сохраняет введённые значения. Исправьте подсвеченное поле и
повторите сохранение.

Если ошибка неизвестная или не связана с конкретным полем, передайте
разработчику `requestId`, показанный в интерфейсе.
